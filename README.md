# TrabajoEntornosDAMGrupo11

El ejercicio que nos ha tocado consistia en un metodo que calculaba el total de precio de una compra aplcandole descuestos y comisiones con varios if. Ese programa constaba unicamente de un metodo CalcularTotal con bastantes parametros, dentro comprobaba la informacion con los ifs para poder aplicar los cambios en el precio, despues de eso devolvia un double con el total

Nos hemos divido el trabajo de forma que:
Daniel hizo la conversion de los numeros hardcodeados a constantes y separo en metodos cada funcion del if quitando trabajo a ese metodo
Martina convirtio los metodos que aplicaban cambios a otra clase y convirtio un parametro a un Enum para su mejor uso
